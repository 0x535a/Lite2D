# Lite2D v0.1.1

macOS 原生菜单栏 Live2D 播放器，面向 Apple Silicon。

## 功能

- 多模型同时显示；每实例独立位置、缩放、动画、表情、追踪和 30/60 FPS。
- 透明窗口与点击穿透，独立编辑、拖动和缩放。
- 按显示器 UUID 保存屏内位置；目标显示器离线时隐藏，重新连接后恢复。
- macOS 原生登录启动开关。
- 新应用图标及 MIT 自有源码许可；模型和专有 SDK 不纳入源码包。

## 验证与限制

构建版本 0.1.1 (2)，ARM64，部署目标 macOS 14+；实测 macOS 27.2 / M3 Pro。显示器绑定版本的 171 项集成、19 项恢复检查及压力后零泄漏检查已记录于 TEST_REPORT.md。Stage Manager、混合 DPI 未测试；物理拔插及部分 Space/全屏行为仍需实际环境验证。OpenGL 已弃用。

自有代码采用 MIT，Live2D SDK、运行库、模型及相关发行许可另行适用，详见 LICENSE 和 docs/THIRD_PARTY_NOTICES.md。

## 安装

下载 ARM64 应用压缩包，解压后将 Lite2D.app 放入 /Applications，再通过菜单导入你有权使用的模型。发布包不包含模型、个人配置或本机日志。应用为 ad-hoc 签名，未公证。
