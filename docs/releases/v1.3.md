# Lite2D v1.3

2026-11-07 · build 13 · 相较 v1.2.1

## 新增与改进

- **群聊窗口**：可创建、命名和管理多个群，将角色台词汇集到独立的透明置顶窗口。每个群可绑定显示器并独立调整位置、大小；调整时提供带头像、左右方向和长消息的完整预览。未入群的角色继续使用模型附近的独立气泡。
- **更自然的台词展示**：台词分句后以打字机效果逐步显示，每句独立计时。通用设置可调整气泡保留时间（1–300 秒，默认 8 秒）；悬停时可关闭单句。角色支持自选圆形头像和左右气泡方向。
- **角色联网搜索**：通过专用 Companion 工具转接 Exa 搜索 MCP，第三方能力仅开放 `web_search_exa`。通用设置 → 主动陪伴 → 搜索工具可控制搜索权限，默认开启；关闭后立即阻止新搜索并取消进行中的请求。返回内容包含来源网址，角色没有通用 Shell、项目编辑或任意第三方 MCP 调用权限。
- **更清楚的角色能力与记忆规则**：并列说明 Observer、搜索、共享记忆和私有记忆的用途与使用时机，强化生活陪伴风格，避免工作进度播报。引导角色保存真实的共同经历、约定和持续话题，不要求每轮记流水账，也不把想象当成事实。
- **共享笔记更易创建**：首次创建笔记无需先读取不存在的文件；修改已有笔记仍须携带当前版本，冲突时重新读取、合并，避免覆盖其他角色的记录。
- **设置页整理**：群与角色在侧栏平级管理；统一页面标题和摆放字段，完善群成员、显示器绑定、调整预览及删除后的回退行为。

## 安装与升级

下载 `Lite2D-1.3-macOS-arm64.zip`，退出旧版后，将解压出的 `Lite2D.app` 放入 `/Applications`。已有模型、布局、Persona、记忆和交流记录保留。首次升级搜索权限时，旧角色上下文会切换到具有新工具权限的独立会话，后续重启继续复用新会话。

版本 **1.3（build 13）**，要求 **macOS 14+ / Apple Silicon（ARM64）**。应用为 ad-hoc 签名、未公证；首次打开可能需要在系统隐私与安全性设置中允许。应用附件不含模型、个人配置、Persona 包或本机日志，附带许可说明和上游许可文本。`SHA256SUMS.txt` 提供应用包与源码包校验值。

Companion 仍依赖本机 OpenCode（本次验证版本 2.2.5）及已配置的模型服务；观察 Codex 需本机 CLI，仅 Claude 历史读取需 Node.js 24+。联网搜索会将搜索词与搜索目的发送给 Exa，受网络和服务可用性影响；提示词禁止将工作观察、记忆或个人数据发送到搜索服务。启用观察来源后，筛选出的授权工作会话内容仍可能发送给所配置的模型服务。

源码包为发布提交的 Git 快照，不包含第三方 submodule 内容和专有运行库；构建依赖需另行准备。

## 验证与已知限制

Release 构建与严格签名校验通过；四语资源检查覆盖 339 个键。47 项原生 Companion 检查及真实 OpenCode / MCP 集成验证通过，涵盖双角色独立会话、共享笔记创建、版本冲突、搜索禁用、预算和重启恢复。应用内 Companion 界面、气泡与群设置回归通过；另完成 Exa 搜索 MCP 的真实联网查询。发布附件完成解压、签名和 SHA-256 校验。

这些检查不保证角色每次都使用记忆或搜索，也不代表完整压力与性能套件已经重跑。模型兼容范围延续前版：部分加密 LPK 需要原始 `config.json`，真实 WPK 导出变体仍需验收；不支持 Spine、RAR/7Z、直接打开 MOC/MOC3 或 EX 专用脚本。OpenGL 已弃用，部分多屏、Stage Manager、Space 和全屏场景仍需实机验收。
