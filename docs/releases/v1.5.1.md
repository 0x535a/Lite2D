# v1.5.1 (16) — Conversation & Memory layout repair

This patch addresses the layout and data-presentation defects reported in v1.5.

- Pin the page header below window chrome. Let the browser use remaining height; keep list pagination at the bottom and provide minimum widths for navigation columns.
- Match native settings structure: L1 uses a state form, legacy diary has an explicit return route, and irrelevant filters are removed. Conversation rows include actual text previews. Empty lists show a generic record state; pagination states the page count and record count.
- Separate enum translation from arbitrary data. Missing enum translations fall back to their value, empty metadata is omitted, and names/numbers are never replaced with ellipses. Timestamps use the local time zone with the original value preserved in data.
- Show current/historical Persona revisions accurately; omit restore actions for identical source and reject no-op restore previews.
- Bound the confirmation sheet, scroll its contents, keep action buttons fixed, and show selected memory and actual status changes for archive/restore/forget operations.
