# Lite2D v1.5.1

2026-11-10 · build 16 · 相较上一公开版本 v1.3

本次发布汇总 v1.4 的记忆架构升级、v1.5 的 Conversation & Memory 管理面板，以及 v1.5.1 的排版与数据显示修复。

## 新增与改进

- **结构化角色记忆**：增加事件、事实、信念、观点、技能、习惯、关系与反思等记忆类型，记录所有者、来源、证据、时间、有效期和修订链。支持本地全文检索、纠错和遗忘；角色仍只能访问获准的私有记忆与共享内容。
- **版本化 Persona**：保存用户人设原文与修订历史，支持差异预览、版本恢复和单独生成运行时视图。角色可以获取对方的公开身份卡；身份变更会切换角色会话策略，减少旧上下文覆盖新身份的问题。旧日记保留为未分类资料，不自动升格为身份事实。
- **方向性关系与背景初始化**：分别记录“我如何看待对方”，支持管理员预览、提交及撤销关系背景。合成背景与真实发生的对话、亲历、观察和转述保持不同来源。
- **可审核的反思与成长**：提供证据摘要预览、通过、取消与撤销；成长提案要求独立直接证据，并限制可调整字段和每日变化幅度。生成的反思不能作为新的独立经历重复强化自身。
- **全新 Conversation & Memory 面板**：独立原生窗口按角色展示 L0 身份、L1 当前状态、L2 经历、L3 认知、L4 关系与习惯、L5 反思；同时提供全局概览、交流记录、公共笔记和变更记录。支持分页、筛选、搜索、证据跳转及修订历史。
- **原生记忆管理**：支持单条纠错、归档、恢复、遗忘、Persona 版本恢复与反思/成长审核。操作前展示影响预览，提交检查版本冲突；重置会话与遗忘记忆分开处理。
- **面板排版与数据显示修复**：修复内容高度收缩和空白区域，固定标题、分页与确认按钮；L1 改用原生状态表单，旧日记增加返回入口。姓名、数值不再被缺失翻译替换为省略号，时间按本地时区显示；当前 Persona 不再提供无变化的恢复操作。完善四语、深浅色和最小窗口布局。
- **长台词自然分句**：按标点拆分长台词，移除固定字数截断，保留完整内容和每句独立计时。

## 安装与升级

下载 `Lite2D-1.5.1-macOS-arm64.zip`，退出旧版后，将解压出的 `Lite2D.app` 放入 `/Applications`。已有模型、布局、Persona、记忆和交流记录继续保留；数据库会自动迁移到 schema v4。建议升级前备份整个 Lite2D 数据目录；回退旧版时应同时恢复匹配的数据库、Persona 与配置，避免旧版直接使用升级后的数据库。

版本 **1.5.1（build 16）**，要求 **macOS 14+ / Apple Silicon（ARM64）**。应用为 ad-hoc 签名、未公证，首次打开可能需要在系统隐私与安全性设置中允许。应用附件不含模型、个人配置、Persona 包、用户记忆或本机日志，附带许可说明和上游许可文本。`SHA256SUMS.txt` 提供应用包与源码包校验值。

Companion 仍依赖本机 OpenCode 及已配置的模型服务；观察 Codex 需本机 CLI，仅 Claude 历史读取需 Node.js 24+。启用观察来源后，授权会话内容可能发送给所配置的模型服务；联网搜索延续 v1.3 的权限开关与数据边界。

源码包为发布标签对应提交的 Git 快照，不包含第三方 submodule 内容和专有运行库；构建依赖需另行准备。

## 验证与已知限制

- Release 构建、ARM64 架构与严格 ad-hoc 签名校验通过。
- 121 项原生 Companion 检查及真实 OpenCode / MCP 集成通过，覆盖角色隔离、记忆与 Persona 修订、证据链、迁移、遗忘、反思和成长审核。
- Companion 应用回归及窗口几何断言通过，覆盖全局页、L0–L5 与子页面、默认/最小尺寸、四语与深浅色，以及长影响清单下的确认按钮。
- 561 个本地化键 × 四语检查和模型导入回归通过；发布附件解压、签名与 SHA-256 校验通过。

**L1 当前只展示运行时提供的会话、运行状态和话题等信息，临时计划、注意力与即时情绪尚未提供。L5 默认不在后台自动生成：需手动点击“预览记忆巩固”，有至少两条合格独立证据时生成摘要候选，审核通过后形成反思记忆。此流程不调用模型进行深入反思。** 后台模型巩固、向量检索和时间图检索尚未启用；L0–L5 是逻辑分类，不是必须依次填满的升级流水线。

本地遗忘会清理相关记忆及派生内容，但不会删除外部 OpenCode 历史、手动导出或旧备份。普通查看、搜索和刷新不会生成记忆或唤醒模型。测试不保证外部模型的每次判断或角色表现，也不代表完整压力、多屏和性能套件已经重跑。

模型兼容范围延续前版：部分加密 LPK 需要原始 `config.json`，真实 WPK 导出变体仍需验收；不支持 Spine、RAR/7Z、直接打开 MOC/MOC3 或 EX 专用脚本。OpenGL 已弃用，部分多屏、Stage Manager、Space 和全屏场景仍需实机验收。
