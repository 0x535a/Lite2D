# Lite2D v1.2.1

2026-11-05 · build 12 · 相较 v1.0.0

## 新增与改进

- **主动陪伴**：每个角色可导入独立 Persona Markdown，支持主动闲聊、观察 OpenCode / Codex / Claude Code 会话，以及真实的双角色交流、对视、公共与私有记忆。菜单栏提供交流记录、记忆编辑与停止话题；角色设置支持立即触发对话。
- **独立对话气泡**：气泡不抢焦点、不截获点击，各角色可拖动预览调整位置并保存，也可随时重置。
- **原生 Companion 运行时**：调度、预算、队列、记忆、OpenCode HTTP、Codex JSON-RPC 与 MCP 迁入 Swift。仅 Claude 历史读取使用按需 Node SDK 助手，连续查询复用，空闲 60 秒退出。移除旧 JavaScript Controller 及专属依赖，更新共享角色提示词。
- **OpenCode 自动恢复**：启用 Companion 时监控本机 OpenCode 服务，停止或不可达后自动启动；设置页显示启动进度、运行状态和失败原因，失败后退避重试。关闭 Companion 会停止监控，保留 OpenCode 服务运行。
- 改善设置与交流窗口布局，清理角色专用服务的生命周期管理。

## 安装与升级

下载 `Lite2D-1.2.1-macOS-arm64.zip`，解压后将 `Lite2D.app` 放入 `/Applications`。升级前退出旧版，再替换应用；已有模型、布局、Persona 和记忆继续保留。应用包不含模型、个人配置或本机日志。

版本 **1.2.1（build 12）**，要求 **macOS 14+ / Apple Silicon（ARM64）**。应用为 ad-hoc 签名、未公证；首次打开可能需要在系统隐私与安全性设置中允许。`SHA256SUMS.txt` 提供应用包与源码包校验值。

Companion 使用本机 OpenCode 2.2.5，观察 Codex 需要本机 CLI；仅 Claude 历史读取需要 Node.js 24+。模型访问沿用 OpenCode provider 配置。启用对应观察来源后，可读取本机可访问的全部会话，筛选后的内容可能发送给角色配置的模型服务。角色工具不提供 Shell、通用代码执行或项目修改能力；不提供 TTS 或用户聊天输入。详见 [Companion 说明](../COMPANION.md)。

源码包仅包含发布 Git 提交快照；第三方 submodule 和专有运行库需按 `BUILD.md` 单独准备。应用附件附带 MIT、第三方说明及上游许可文本，Claude 历史助手的依赖许可见应用内 `Contents/Resources/Companion/THIRD_PARTY_NOTICES.md`。

## 验证与已知限制

本次发布重新执行 Release 构建、严格签名校验、四语资源检查（301 key × 4）与附件解压/校验值验证。1.2.1 的原生运行时、OpenCode 服务监控及协议回归记录见 `TEST_REPORT.md`；本次不重复完整压力与性能套件。

既有测试中，原生 Companion 包含 35 项检查，并验证真实 OpenCode 协议、双角色独立会话和 SDK 生命周期。单轮本机短测显示原生运行时降低空闲内存占用，未证实 CPU 改善；方法与限制见 [运行时验证](../COMPANION_RUNTIME.md)。

模型兼容范围延续 1.0.0：部分加密 LPK 仍需原始 `config.json`，真实 WPK 导出变体仍需验收；不支持 Spine、RAR/7Z、直接打开 MOC/MOC3 或 EX 专用脚本。OpenGL 已弃用，Stage Manager、混合 DPI、物理热插拔及完整 Space/全屏场景仍未完成实机验收。
