# Lite2D v1.7.0

2026-11-13 · build 18 · 本地安装构建说明，未创建公开发布附件。

本次将生活陪伴的主动性接入原生 Runtime：先把获准的观察归一化成短期机会，再由确定性策略判断时机。角色可选择沉默；计时器不要求角色必须发言。

## 功能

- **Shadow 与有限表达**：共用事件、去重、机会、仲裁和回放。Shadow 不因机会调用角色模型；Live 仍受输入活跃度、勿扰、会话/睡眠、可见性、预算、冷却和统一输出队列约束。
- **持久化未来目标**：真实交流和有效记忆可成为有证据的意图。目标有过期、最大尝试次数和重启复核；可在交流与记忆面板中查看、取消和复核。取消目标不等于删除记忆；遗忘证据会清理派生目标。
- **宏观活动**：只向角色投影类别、置信度和有效期，不自动发送项目、路径、窗口标题、代码、论文或工作消息。旧角色会话策略会更新，以隔离此前的 Observer 正文；既有记忆与 Persona 保留。
- **macOS 原生来源**：前台 App/生命周期、Space 弱线索、输入空闲、睡眠/用户会话、EventKit、Scoped Focus Filter、枚举式活动 App Intent、显式授权目录、电源/热状态、网络、CoreAudio 环境和白名单窗口本地分类。新来源与分享默认关闭，授权按钮不在后台触发系统提示。
- **日历差分**：只含时间与状态，支持静默基线、更新、首次可见、提醒完成、不可见及计划时间边界。读取失败不当成空集合；更新/完成使旧提醒机会失效；不把计划开始/结束当作现实活动发生。
- **实验通知适配器**：只读 usernoted，按 App 白名单启用；默认不查询正文，SQLite authorizer 阻止意外 BLOB 读取。可选本地分类仍不保存或远传标题/正文。支持 WAL 变化、去重、游标、数据库重建和可观测的覆盖缺口。
- **实际表达回执**：模型生成、排队、真正可见、完成和角色实际消费分别记录。未展示或未消费的候选不会作为角色亲历写入每日记忆。
- **独立模型与轻量认知**：每角色模型和记忆整理模型可分别选择；状态绑定 characterId。好奇、社交倾向、表达精力与短期情绪有界衰减，不因沉默制造社交债务。
- **权限与管理**：来源、分享和来源可见角色分别控制；决策审计保存 1、24 或 168 小时。清除交流历史同步清除表达回执与决策，保留显式记忆。气泡尊重减少动态效果和减少透明度偏好。

## 升级

退出旧版，备份应用和完整 Lite2D 数据后替换 `/Applications/Lite2D.app`。保留模型、布局、Persona 和长期记忆；主动性使用增量表，不重命名既有记忆表。新开关不会因升级自动开启。回退应同时恢复匹配的数据备份。

App Intents 的真实元数据随构建生成并参与签名。Focus 需要用户在系统设置中绑定本 App Filter；它不能枚举系统全部专注模式。显式活动输入只接收固定枚举，五分钟后失效。

## 验证边界

已通过323项原生 Controller/SQLite 检查、真实 OpenCode/MCP 与本地确定性模型集成、261项应用自身窗口/气泡检查、模型导入和704键×4语言检查；显示器绑定/恢复与渲染另有应用内集成回归。测试不使用付费模型或 computer use，也不默认读取用户真实日历、通知或窗口标题。最终检查数量与安装结果记录在本地验收文档中。

30 秒 Off/On 感知对照中，增量约为单核 CPU **0.113 个百分点**、进程树 footprint **1.50 MiB**，没有模型请求或 Node helper；这是无渲染、无敏感来源的单次有界测量，不能当作整机长期能耗结论。可用 `python3 scripts/profile_perception.py --seconds 30` 复跑。

实测主机为 macOS 27.2 / Apple Silicon。主程序 minos 为 14.0，但本地 Cubism Core 静态库报告 15.7 构建目标，尚不能声称完成 macOS 14 真机兼容验收。应用保持 ad-hoc 签名，TCC 授权保留需由系统与实际授权场景确认。

真实 EventKit 授权/撤销、Focus 设置发现与绑定、AX/FDA、五类真实通知、iPhone 镜像/Live Activities、音频热插拔、物理显示器切换等仍需在用户显式启用对应能力后逐项场景验收。合成夹具、编译成功和监听注册不代替这些验证。

API 研究清单中的 Wi-Fi 身份、BLE 扫描、曲目读取、Contacts、Photos、位置、浏览器/Finder/邮件/Notes 专用集成、剪贴板、天气、iPhone/Watch/Home 桥接仍为条件性扩展。本次首版未接入这些来源，也未增加 TTS、健康数据或持续屏幕 OCR。Foundation Models / NL / MLX 保留为可替换实现候选，当前宏观分类使用本地规则。
