# Lite2D v1.0.0

2026-11-03 · 首个 1.0 正式版 · 相较 v0.1.1

Lite2D 是面向 Apple Silicon 的 macOS 原生菜单栏 Live2D 播放器，支持多个独立控制的角色，兼容 Cubism 3+ 和旧版 Cubism 2 模型。

## 新增功能

- **模型包导入**：支持 LPK、WPK、ZIP、模型 JSON 和完整模型文件夹；可从设置窗口拖入。多角色包支持勾选导入，关联服装保留在同一角色下。资源复制到应用模型库，原包移动或删除后仍可使用，相同资源快照复用存储。
- **独立服装切换**：识别模型的 `change_cos` 服装引用，显示作者提供的名称。各实例分别记忆服装，复制、撤销移除和重启后保留；切换失败保留原服装。
- **动作权重**：自动播放按模型权重及实例覆盖值随机选播，支持逐组编辑、零权重排除和恢复默认值。手动预览结束后恢复循环动作。
- **点击互动**：每个角色可选择点击动作组，在保持窗口穿透的同时响应可见区域单击；透明区域和拖动不触发，重叠时只响应最上层角色。底下应用同时正常接收点击，互动默认关闭。
- **原生分组设置窗口**：左侧选择角色，右侧按外观与摆放、动作与互动、高级分组；支持直接改名、即时保存、复制、移除和撤销，菜单保留角色快捷操作。
- **四语界面**：简体中文、繁体中文、英语、日语；支持跟随系统或手动选择，应用界面即时切换，保留当前页面、角色选择和编辑状态。

## 修复与改进

- 修复旧版动作播放时覆盖模型作者眼睑参数的问题。
- 导入使用原生选择界面，检查缺失资源、损坏归档、路径越界、符号链接及文件名冲突。
- 兼容旧缓存服装的 `.bin` / `.json` 引用差异；切换保留位置、显示器绑定、追踪、暂停及帧率设置。
- 规范化部分紧凑数字模型 JSON，并检查 SDK 解析结果，改善原生模型包兼容性。
- 延续多角色独立布局、显示器 UUID 绑定、离线隐藏恢复、30/60 FPS 与登录启动。

## 安装与升级

下载 `Lite2D-1.0.0-macOS-arm64.zip`，解压后将 `Lite2D.app` 放入 `/Applications`。升级时先退出旧版再替换应用，已有配置和角色资源继续保留。应用包不包含模型、个人配置或本机日志。

版本 **1.0.0（build 4）**，要求 **macOS 14+ / Apple Silicon（ARM64）**。应用为 ad-hoc 签名，未公证；首次打开可能需要在系统隐私与安全性设置中允许。`SHA256SUMS.txt` 提供应用包与源码包的校验值。

源码包仅包含当前 Git 提交快照；第三方 submodule 及专有运行库需按 `BUILD.md` 单独准备。发行包附带 MIT、第三方说明及相关上游许可文本；第三方组件与模型各自的许可继续适用。

## 验证与已知限制

- 本次 Release 构建与严格签名校验通过；四语资源（210 key × 4）、模型导入、设置迁移与校验回归通过；应用内集成 **350 项**、新进程恢复 **19 项**全部通过。完整记录见 `TEST_REPORT.md`。
- 系统弹窗的语言可能需要重启应用后更新；作者提供的信息与用户自定义名称保留原文。
- 部分加密 EX 工坊 LPK 需要同目录原始 `config.json`。WPK 外层结构已用构造包验证，真实导出变体仍需样本验收。
- 不支持 Spine、RAR/7Z、直接打开 MOC/MOC3、EX 对话、语音或专用脚本；旧版 ViewerEX 专用控制器未完整实现。
- OpenGL 已弃用。Stage Manager、混合 DPI、物理显示器热插拔及全部 Space/全屏场景仍未完成实机验收。
